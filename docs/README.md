`AGENTS.md` (`main → AGENTS.md → docs/GOVERNANCE.md → Issue/PR ativa →
checks/artifacts/runtime → checkpoint como histórico`). Este arquivo **não** é
fonte de estado mutável: ele só diz onde cada coisa vive.
